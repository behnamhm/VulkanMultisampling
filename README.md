# Graphics Engine

A modern graphics engine built from scratch using **Vulkan** and **C++17**.

This project is focused on learning and implementing modern real-time rendering techniques while building a clean, modular, 
and extensible rendering engine. The goal is to gain a deep understanding of Vulkan by implementing every major 
rendering system from the ground up.

---

## 💻 Supported Platforms

The engine is designed to be cross-platform and currently supports:

- ✅ Windows
- ✅ macOS
- ✅ Linux

---

## 🛠 Technologies

| Technology | Description |
|------------|-------------|
| **Language** | C++17 |
| **Build System** | CMake |
| **Graphics API** | Vulkan |
| **Window Library** | GLFW |

---

## 📁 Project Structure

| Folder | Description |
|--------|-------------|
| `source/` | Engine source code |
| `thirdparty/` | External dependencies |
| `assets/` | Shaders, textures, and resources |
| `CMakeLists.txt` | Project configuration |

---

## 🚀 Building the Project

### Recommended

Open the repository root directly in any CMake-compatible IDE:

- Visual Studio
- Visual Studio Code
- CLion

The project should configure automatically.

---

### Using the Batch Script

If you're using the provided batch script, make sure the Visual Studio generator matches the version installed on your machine.


| Visual Studio | CMake Generator |
|---------------|-----------------|
| Visual Studio 2019 | `Visual Studio 16 2019` |
| Visual Studio 2022 | `Visual Studio 17 2022` |
| Visual Studio 2026 | `Visual Studio 18 2026` |
